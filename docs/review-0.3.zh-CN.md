## 后续修复与复核

- EWS 对象采用服务器 MAC 标识：密钥从主密钥环按账号身份进行域分离派生，绑定端点、邮箱和对象类型；只从限定邮箱的响应生成。原始、其他账号/邮箱、篡改和错误类型的标识在出站前拒绝。附件绑定父邮件并检查当前成员关系，文件夹限定邮件类型/角色；8 个操作均有回归覆盖。
- 搜索文件夹和移动目的地参数统一支持 4000 字符标识；长原生文件夹 ID 经真实 provider、工具 schema 和 MailService 验证。旧密钥保留期间旧标识可用，退休后的失效/重新检索要求已写入运维说明。
- EWS 创建联系人的字段顺序与微软 Contact 定义/示例对齐；未声称完整 Exchange XSD 或品牌兼容认证。
- 新增 `native_drafts_inspect` 只读检查双方内容和当前版本，保留 conflict/unknown，解决操作仍重新读取并比较版本。远端检查失败时保留本地停止关联操作和其他行。
- MCP Apps 保存期间保留新输入并采用保存结果的 revision；选择变化、准备期间编辑后不显示旧确认链接。搜索/阅读响应有序号保护，新搜索立即清除旧分页。
- 共享私有数据说明明确指应用草稿；原生草稿仍是共享邮箱内容。在线 token 撤销与已批准发送/已启用自动写回的持久授权分别说明。

首轮远程 CI 的浏览器步骤检出移动端数据保留 JSON 溢出（检查/数据库/OCR/审计均通过）。改为中文策略说明，新增较宽回退字体断言；本地使用与 CI 同版本的 Playwright Chromium 验证。随后远程浏览器交互通过，OIDC 用例检出退出后立即登录的导航竞争；用例改为等待完整退出导航，实际 Keycloak 本地复跑通过，未调整业务鉴权。

复核覆盖改动本身、调用链及负例，不以缺少现场账号作为安全反证。
