# 0.3.0 实现与验证状态

日期：2026-11-04。当前代码、边界与证据以此文档、[0.3 记录](release-0.3.zh-CN.md) 和 [TODO](../TODO.md) 为准；原调研/架构保留为历史设计。

## 已实现

原 0.1/0.2 邮件、MCP、OIDC、持久草稿/发送授权、同步、IDLE/鉴权推送、主权云与 JMAP 白名单保留。本轮新增：

- People/CardDAV 联系人、Graph 个人/共享联系人授权；本地 EWS Basic/Bearer 指定邮箱适配，管理员精确 origin 和网络目的地限制。
- MCP Apps 邮箱选择、搜索/阅读、附件资源、To/Cc/Bcc 草稿编辑/回复/保存及独立确认链接；可选宿主文件输入与标准 MCP 文件资源输出。
- Gmail/Graph 原生草稿导入、周期拉取、显式自动写回、双方冲突/未知结果停止、版本化处理与停用竞争控制。Graph 小于 3MB 文件附件可替换并回读字节身份。
- PPTX/XLSX/OpenDocument/RTF/HTML 提取、受限离线 PNG/JPEG OCR、显式附件私有索引/中文子串检索/删除。
- 同租户 subject 授权与读/写/发送分离，凭证所有者管理，使用者私有应用草稿/上传/索引；撤权/降权/到期与旧审批取消。
- 可选逐请求 introspection（含网页会话）、scope 交集、故障关闭；密钥 ID/旧 key 环与 dry-run/apply 轮换；保留配置、引用保护、发送台账保留。
- schema v3、升级/回退门槛与配置文档；默认不自动删除用户草稿或审计。

## 证据层次

已有 PGlite/独立 PostgreSQL、真实 HTTP MCP SDK、TLS/STARTTLS IMAP/SMTP、浏览器/移动布局、实际 Keycloak 登录证据；新增 ACL/轮换/保留/同步竞争、XML/EWS/联系人契约、MCP 文件读取、图片 OCR 与 IdP 撤销实验见 [0.3 记录](release-0.3.zh-CN.md)。正式扫描与远程 CI 以实际回执为准，不能用旧版记录代替。

## 明确边界

1. QQ/163/iCloud/Workspace/M365/各云/共享邮箱/企业内网/JMAP/Proton Bridge/Exchange 均仍需真账号与部署验收；HTTP 契约和本机协议实验不是品牌认证。
2. 宿主安装、真实文件库、ChatGPT web/desktop/mobile UI/知识检索、公共目录审核未完成；不伪造官方内部 file_id 或无鉴权公共附件链接。
3. Gmail 原生草稿更新缺少已核实的原子 CAS；Graph 附件写回是多请求，部分结果可为 unknown；单文件达到 3MB 需要未实现的上传会话路径，当前写前拒绝。IMAP/JMAP/EWS 使用应用草稿，不伪装原子原生更新。
4. CardDAV 是显式地址簿、前 500 条有界快照；EWS 是受批准端点的有限适配，没有 NTLM/Kerberos、自动发现或全域模拟。各云租户的授权/条件访问/别名仍须验证。
5. OCR 只覆盖显式 PNG/JPEG，不做扫描 PDF 页面渲染；格式提取不是全保真 Office 转换。解析 worker/原生 OCR 不等于 OS 恶意文件沙箱。
6. 附件索引仅覆盖用户主动选择的私有快照，缓存也仅是已同步范围；不提供全邮箱完成证明、语义向量索引或企业全域目录扫描。
7. token 在线撤销阻止后续交互；已持久批准的发送和明确启用的原生草稿自动写回仍按原授权执行，直到被取消或账号/共享权限撤销。已发出的外部请求不能承诺召回。
8. 生产压测、灾难恢复、真实升级回退、密钥管理设施和数据库/备份加密需部署方验收；公开仓库仍为 UNLICENSED，许可证待项目所有者决定。
